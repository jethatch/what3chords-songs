    How it works

    Three chords for every place

    The planet is divided into about 570 trillion hexagons, each under a square metre, using the H3 grid. Each hexagon’s ID is shuffled and rewritten as a three-digit number in base 167,011 — the number of guitar chord voicings in the code book. Three digits, three chords. Click anywhere on the map to hear a spot.

    The shuffle has a side effect worth listening for: a place shares its first chord with the region around it, like an accent, while its third chord changes from one doorstep to the next.

    A trip is a song

    Enter a start and an end. The route between them is a chain of hexagons, sized so the trip has a sensible number of stops, and each stop plays the chords of the place it stands on.

    • Hex walk is greedy local routing: at every hexagon, step to the neighbour nearest the destination. It runs entirely in your browser and cheerfully crosses oceans.
    • Follow roads asks the public OSRM demo server for a driving route and collects the hexagons along it. If the server is down, no road connects the two places, or a pin is far from any road, you get the hex walk instead.

    Playing it

    Choose a time signature, tempo and strum pattern, then press play (or the space bar). Changes to the rhythm take effect at the next bar line, so you can rearrange the song while it plays. Select any stop in the chord chart to jump there.

    On an iPhone, flip the ring/silent switch to ring if you hear nothing.
